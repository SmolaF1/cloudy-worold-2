# Cloudy Worold 2

Публичный сайт Minecraft-сервера. Контент и дизайн смоделированы по образцу реального
сервера [cloudyworlds.ru](https://cloudyworlds.ru) (владелец сервера подтвердил, что это
его собственный проект) — тексты правил и вики перенесены почти дословно, ссылка на Discord
актуальная (`https://discord.gg/DKUdvZEhP`).

**Живая версия:** https://smolaf1.github.io/cloudy-worold-2/
**Репозиторий:** https://github.com/SmolaF1/cloudy-worold-2

## Что это технически

Обычный статический сайт — чистые HTML/CSS/JS, без фреймворков и без шага сборки.
Хостится на GitHub Pages прямо из ветки `main`.

- `index.html` — главная страница (hero с анимированным ночным небом, устройство
  мира, режим, техническая база, сервисы, маршрут входа, правила кратко, команда,
  финальный CTA, футер)
- `rules.html` — полный свод правил (10 разделов, боковое меню, живой поиск по тексту,
  цветные теги мер наказания)
- `wiki.html` — вики сервера (F.A.Q., команды, плагины, механики, разрешённые/запрещённые
  моды, книга рецептов пивоварения с поиском, чек-лист новичка с сохранением в
  localStorage, словарь терминов, хроники сезонов)
- `assets/base.css` — общие стили (переменные темы, шапка, кнопки, футер, базовая
  типографика секций), подключаются на всех трёх страницах
- `art/kaezo.png` — аватар одного из модераторов в разделе «Команда»

Шрифты: Unbounded (заголовки), Onest (текст), JetBrains Mono (код/данные) — через
Google Fonts. Палитра: тёмно-синий фон + золотой акцент, весь текст светлый.

## Как вносить правки

Файлы правятся локально в `C:\Users\user\cloudyworld-site`, затем:

```bash
git add -A
git commit -m "описание правки"
git push
```

GitHub Pages пересобирает сайт автоматически, обновление занимает 1–2 минуты.

## История и контекст

- Изначально сайт задумывался как демо-макет с придуманными данными, затем
  переориентирован на реальный сервер cloudyworlds.ru по просьбе владельца.
- Планы на бэкенд с настоящим Discord-входом и ботом (OAuth, автовыдача роли)
  были начаты (Next.js-проект), но отменены — на сайте это осталось просто
  текстом-описанием процесса, без реальной логики входа.
- Node.js и GitHub CLI (`gh`) были установлены на эту машину через `winget`, чтобы
  можно было создать репозиторий и включить GitHub Pages прямо из терминала.
  Аккаунт GitHub, под которым всё опубликовано: **SmolaF1**.
- Проект переименован из «CloudyWorld» в «Cloudy Worold 2» по явному запросу —
  название только косметическое, реальный адрес сервера (`play.cloudyworlds.ru`)
  и ссылки на настоящий Discord не менялись.
