# CloudyWorld

Статический сайт-лендинг сервера. Один файл `index.html` — HTML, CSS и JS уже внутри,
никакой сборки не требуется.

## Проверить локально

Просто открой `index.html` в браузере, либо подними локальный сервер:

```bash
npx serve .
```

## Разместить на своём домене

Годится любой статический хостинг. Проще всего:

### Netlify (проще всего)

1. Зайди на [app.netlify.com/drop](https://app.netlify.com/drop) и перетащи туда
   папку с `index.html` — сайт будет опубликован сразу.
2. В настройках сайта → **Domain management** → **Add a domain** впиши свой домен
   и следуй инструкции по DNS (Netlify подскажет, какие записи добавить у
   регистратора домена).

### Vercel

```bash
npx vercel --prod
```

Затем в панели Vercel → Settings → Domains добавь свой домен.

### GitHub Pages

1. Создай репозиторий, положи туда `index.html`.
2. В настройках репозитория → **Pages** → Source: ветка `main`, папка `/`.
3. Во вкладке **Custom domain** впиши свой домен и создай в DNS запись
   `CNAME` на `<username>.github.io` (или `A`-записи на IP GitHub Pages).

## Что поправить перед реальным запуском

В файле помечено как «пример данных» / «демо-данные»:

- IP сервера и версия (`play.cloudyworld2.net`, `1.21.4`)
- Онлайн игроков (`84 / 200`)
- Правила, состав команды и ссылка на Discord (`discord.gg/cloudyworld2`)

Раздел «Маршрут» (вход через Discord, заявка, автовыдача роли) сейчас просто
описывает процесс текстом — кнопок и настоящей логики входа на странице нет.
Если такая система понадобится, это отдельный проект с бэкендом (Discord OAuth
+ бот для выдачи роли), не статический сайт.
